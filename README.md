## Featured Projects

### 🛡️ ShadowWatch
A Windows security monitoring tool combining a Python backend with a real-time HTML dashboard. Built with SMB/KMU (small business) deployment in mind — practical, lightweight endpoint visibility without enterprise overhead.

### 📦 Windows Sandbox Application
A C++ sandboxing tool (ImGui/DirectX 11 UI) that isolates untrusted processes using **Job Objects**, **Restricted Tokens**, and **AppContainer**-based restrictions across filesystem, registry, and network access.

A C++ desktop moderation tool built with ImGui, designed for fast, low-overhead moderation workflows.
